A modern, responsive website for RGC Technologies, showcasing their CMMS (Computerised Maintenance Management System) solutions.

## 🚀 Tech Stack

- **Frontend Framework**: React 19.2.0
- **Build Tool**: Vite 7.2.4
- **Icons**: Lucide React
- **Styling**: Vanilla CSS with custom design system

## 📋 Features - 

- **Modern Design**: Premium UI with custom color palette and typography
- **Responsive Layout**: Optimized for all device sizes
- **Component-Based Architecture**: Reusable React components
- **Custom Illustrations**: AI-generated hero imagery
- **Professional Icons**: Lucide React icon library

## 🛠️ Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd Website
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

The site will be available at `http://localhost:5173/`

## 📦 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

## 📁 Project Structure

```
src/
├── components/
│   ├── Header.jsx       # Navigation bar
│   ├── Hero.jsx         # Hero section with CTA
│   ├── InfoSection.jsx  # Value proposition
│   ├── Savings.jsx      # ROI statistics
│   ├── WhyChooseUs.jsx  # Benefits grid
│   ├── News.jsx         # Client testimonials
│   └── Footer.jsx       # Footer links
├── assets/              # Images and static files
├── index.css           # Global styles & design tokens
├── App.jsx             # Main app component
└── main.jsx            # Entry point
```

## 🌟 Key Sections

1. **Hero**: Introduction to JOBPAL with contact information
